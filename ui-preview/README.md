# Box AI — Tampilan Utama (UI Preview)

Ini **tampilan utama** Box AI (HTML prototype v4).

## Cara buka
1. Buka `index.html` di browser (Chrome / HP)
2. Atau serve lokal: `npx serve ui-preview`

## Isi
- `index.html` — struktur layar
- `styles.css` — tema dark Box AI
- `app.js` — navigasi & interaksi
- `assets/` — logo cube
- `screenshots/` — referensi layout

Sumber desain: Box-AI-UI-HTML-v4 (dijadikan tampilan utama repo).
