# Box-Ai UI source reference

Source archive: `Box-Ai-UI-v2_2_34-pro2(1).zip` supplied by the project owner.

This directory contains the original Box-Ai WebView presentation files (`index.html`, `styles.css`, `app.js`, and logos) for visual/interaction reference. The archive itself states it does not include the native Kotlin/backend/inference project. These files are not yet mounted in the PocketPal React Native app; use them to port the Box-Ai appearance and visible feature controls onto PocketPal's stores/services.

Keep the Box-Ai UI attribution and license in `LICENSE-BOXAI-UI` when these files or substantial portions are distributed.
